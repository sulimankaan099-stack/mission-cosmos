# 🚀 Mission Cosmos

### Space Mission Building System

Mission Cosmos is a Python-based space mission simulation project designed to demonstrate fundamental programming concepts through a space-exploration scenario.

## 🌌 About the Project

Mission Cosmos allows users to enter mission-related information and generates a structured mission overview based on the provided data.

The project combines Python fundamentals with a space-science theme to create a practical and interactive command-line application.

## 🛠️ Technologies & Concepts

- **Python 3** — Core programming language
- **Variables & Data Types** — Managing mission information
- **User Input** — Collecting mission parameters interactively
- **Type Casting** — Converting user input into appropriate data types
- **Conditional Statements** — Processing mission conditions
- **Loops** — Managing repeated operations
- **F-Strings** — Formatting mission information
- **Command-Line Interface (CLI)** — Running the application through the terminal
- **Git & GitHub** — Version control and project management

## 🎯 Project Objective

The main objective of Mission Cosmos is to strengthen Python programming fundamentals by applying them to a practical space-mission scenario.
